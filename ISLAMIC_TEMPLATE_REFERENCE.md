# Islamic Mothers Template - Variable Reference

## Template Created
**Name:** Islamic Mothers - Professional  
**Description:** Professional Islamic-themed design with bonus gift section, calendar integration, and social sharing

## All Variables Used

### Webinar Information
- `{{webinarTitle}}` - Used in: Page title, social sharing
- `{{webinarDescription}}` - Used in: Header subtitle
- `{{webinarDuration}}` - Used in: Webinar details section
- `{{webinarDate}}` - Used in: Calendar details
- `{{webinarTime}}` - Used in: Calendar details
- `{{timeZone}}` - Used in: Time display

### Host Information
- `{{hostName}}` - Used in: Institution name header, footer
- `{{hostEmail}}` - Used in: Footer contact link

### Attendee Information
- `{{attendeeName}}` - Used in: Header greeting, bonus section
- `{{attendeeEmail}}` - Used in: Bonus section confirmation
- `{{registrationId}}` - Used in: Footer (small print)

### Dynamic Links
- `{{joinLink}}` - Used in: Social sharing, join webinar button
- `{{calendarLink}}` - Used in: Add to calendar button

### Interactive Elements
- `{{countdown}}` - Used in: Countdown timer script section

## Template Features

### 1. Professional Header
- Gradient background with pattern overlay
- Institution name display
- Success animation with checkmark
- Personalized greeting with attendee name

### 2. Bonus Gift Section
- Prominent gift announcement
- Placeholder for bonus image
- Description of what attendees will receive
- Email confirmation

### 3. Next Steps Cards
- **Card 1: Mark Your Calendar**
  - Full webinar details (date, time, duration, platform)
  - Add to calendar button
  - All details pulled from webinar data

- **Card 2: Share & Inspire Others**
  - WhatsApp sharing button (pre-filled message with webinar title and link)
  - Facebook sharing button
  - Inspirational hadith quote
  - Copy link button with success feedback
  - Join webinar room button

### 4. Countdown Timer
- Large, centered countdown display
- Shows days, hours, minutes, seconds
- Auto-updates every second
- Injected via {{countdown}} variable

### 5. Professional Footer
- Host name display
- Quick links (About, Contact, Privacy)
- Copyright notice
- Registration ID for reference
