3. Select "Deploy from GitHub repo"

### 2. Add PostgreSQL Database
1. In your Railway project, click "+ New"
2. Select "Database" → "PostgreSQL"
3. Railway will automatically create a database
4. Copy the `DATABASE_URL` from the PostgreSQL service

## Post-Deployment

### Update NEXTAUTH_URL
Once deployed, get your Railway URL (e.g., `https://your-app.up.railway.app`) and update:
1. Railway environment variable `NEXTAUTH_URL`
2. Redeploy (Railway auto-redeploys on env changes)

### Test Your Deployment
1. Visit your Railway URL
2. Log in with admin credentials
3. Create a test webinar
4. Test registration flow
5. Check Railway logs for Facebook Conversions API success messages

## Troubleshooting

### If Build Still Fails
Check Railway logs for specific errors:
```bash
railway logs --deployment
```

### If Database Connection Fails
Make sure `DATABASE_URL` is set and Prisma migrations are run:
```bash
railway run npx prisma migrate deploy
```

### If App Won't Start
Check that all required environment variables are set:
- `DATABASE_URL`
- `NEXTAUTH_URL`
- `NEXTAUTH_SECRET`
