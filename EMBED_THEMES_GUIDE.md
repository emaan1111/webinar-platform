## 🔧 How to Use

1. Go to **Dashboard → Webinars → Edit Webinar**
2. Scroll to **Embed Code Generator** section
3. Select your preferred theme:
   - **Registration Style** - For main landing pages
   - **Corporate** - For professional B2B
   - **Material** - For modern web apps
   - **Playful** - For fun/casual events
4. Copy the embed code
5. Paste on your external website
