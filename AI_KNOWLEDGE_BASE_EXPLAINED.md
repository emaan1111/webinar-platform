## 🔧 How AI Uses These Documents

### 1. **System Prompt** (AI's Instructions)
```
You are a helpful assistant for the "[Webinar Title]" program.

Your role is to answer questions about the program ONLY.

Rules:
1. ONLY answer questions related to the program, pricing, curriculum, 
   benefits, or logistics.
2. Be friendly, professional, and concise.
3. If someone asks something off-topic, politely redirect them.
4. Use the program information provided to give accurate answers.
5. If you don't have the information, say "I don't have that specific 
   information, but I can connect you with our team."
6. Encourage interested attendees to take action.
7. Never make up information - only use what's provided.
```

### 2. **Document Context** (All Your Documents Combined)
```
=== PROGRAM INFORMATION ===

## Program Overview
[Your overview content here]

## Pricing & Payment Plans
[Your pricing content here]

## Frequently Asked Questions
[Your FAQ content here]

## Program Curriculum
[Your curriculum content here]

## Student Success Stories
[Your testimonials here]
```

### 3. **User Question**
```
"What's included in the program?"
```

### 4. **AI Response Process**
1. AI reads the question
2. AI searches through all document context
3. AI finds relevant information in "Program Overview" section
4. AI formulates a friendly, accurate response
5. AI posts response to chat

## 💡 Best Practices

### ✅ DO:
- **Be specific** - Include exact numbers, dates, prices
- **Be comprehensive** - Cover all common questions
- **Use clear language** - Write as you'd explain to a friend
- **Update regularly** - Keep prices and dates current
- **Include details** - More information = better AI responses

### ❌ DON'T:
- Don't be vague ("affordable pricing" → say "$297")
- Don't use jargon or complicated terms
- Don't leave out important details
- Don't contradict yourself across documents
- Don't include outdated information

## 🎯 Adding Documents to Your Webinar

### Via API:
```bash
POST /api/webinars/YOUR_WEBINAR_ID/program-documents
Content-Type: application/json

{
  "title": "Program Overview",
  "content": "Your detailed content here...",
  "category": "overview",
  "isActive": true,
  "sortOrder": 0
}
```

### Categories Available:
- `overview` - General program info
- `pricing` - All pricing details
- `faq` - Questions & answers
- `curriculum` - Course content breakdown
- `testimonials` - Success stories
- `general` - Other relevant info

## 🐛 Troubleshooting

### "AI gives generic answers"
➡️ Add more specific details to your documents

### "AI doesn't answer a question correctly"
➡️ Check if that information exists in your documents  
➡️ If not, add it to the appropriate document

### "AI responds with 'I don't have that information'"
➡️ Good! This means the info isn't in your documents  
➡️ Add the missing information
